Sobre mí

Lógica primero, soluciones claras

Pensamiento estructurado para pasar de esquema de datos a funcionalidad usable.

Soy Francisco Curbelo, desarrollador en formación con ganas de construir soluciones prácticas con código claro.

Base en Java, PHP, SQL y desarrollo web. Me centro en lógica, estructuras de datos y arquitectura ordenada.

En IES Lomo de la Herradura trabajo con Java para sistemas de gestión y diseño de bases de datos relacionales. En Fraemma participé en la migración y desarrollo de un ERP/CRM privado con PHP y Laravel (aplicación interna, backend, funcionalidades internas, bases de datos y lógica).
